# Bank-Loan-Analysis-Dashboard
Interactive Bank Loan Analysis Dashboard built using Microsoft Excel, PivotTables, charts, and slicers to analyze loan trends and borrower information.
Bank Loan Analysis Dashboard

Project Overview

An interactive Excel dashboard developed to analyze bank loan data and identify trends in loan applications, revolving balances, verification status, and borrower characteristics.

Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Slicers for interactive filtering
- Data analysis and visualization

Dashboard Features

- Loan application trends by year
- Revolving balance analysis by grade and sub-grade
- Verified versus non-verified loan status
- Analysis by home ownership
- Interactive slicers for year, home ownership, and loan grade

Key Objective

To transform bank loan data into an interactive visual dashboard that helps users explore loan patterns and borrower information.
